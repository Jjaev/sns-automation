# 🎴 AI 카드뉴스 제작 서비스

> AI가 카드뉴스 10장을 5분 만에 만듭니다
> 모든 이미지는 실제 PNG, 텍스트 깨짐 없음, 브랜드 컬러 일관

---

## 서비스 범위

| 항목 | 제공 |
|------|------|
| 슬라이드 수 | 8~10장 (1080×1080px) |
| 포맷 | PNG / JPG / PDF |
| 브랜딩 | 브랜드 컬러 + 폰트 + 로고 적용 |
| 리터칭 | 슬라이드당 1회 무료 수정 |
| 배포 | Google Drive / Notion / 직접 전송 |
| 소요 시간 | 12시간 이내 (일반 4~6시간) |

---

## 가격

| 유형 | 설명 | 가격 |
|------|------|------|
| **스타트업 패키지** | 카드뉴스 10장 + 브랜드 세팅 | **10만원** |
| **월 정기권** | 주 2회 (월 8회) + 브랜드 유지 | **29만원** |
| **기업 맞춤** | 무제한 수정 + 긴급 제작 + 다양한 포맷 | **49만원/월** |

---

## 작업 프로세스

```
1. 주제 확정 (고객 제공 또는 추천)
2. 프레임 선정 (PAS / BAA / 리스트)
3. 카피 초안 → 고객 확인 (Now)
4. AI 슬라이드 제작 → PNG 변환
5. 최종 전달 (Google Drive)
```

---

## 차별점

- ✅ **AI 제작 품질**: 사람 손길 + AI 속도. 품질 떨어지지 않음
- ✅ **운영 무제한 수정**: 고객이 만족할 때까지 (패키지 따라)
- ✅ **Notion 템플릿 연동**: 카드뉴스와 SNS 포스팅을 하나의 시스템에서
- ✅ **브랜드 일관성**: 로고/컬러/폰트가 모든 슬라이드에 동일 적용
- ✅ **빠른 대응**: 일반 4~6시간, 긴급 2시간
