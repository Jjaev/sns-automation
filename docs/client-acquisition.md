| 액션 | 상세 |
|------|------|
| 콘텐츠 업로드 | 포트폴리오 샘플 3건 → 주 3회로 확대 |
| 바이오 링크 | "SNS 관리 필요하세요? DM 주세요" + 크몽 링크 |
| 해시태그 | #인스타관리대행 #SNS마케팅 #자영업자마케팅 등 타겟 태그 |
| DM 웰컴 | 신규 팔로워에게 자동 DM (또는 템플릿 저장) |

**효과**: 3개월 운영 후 월 10~20건 문의 기대

| 액션 | 상세 |
|------|------|
| 서비스 등록 | 위 프로필 기반으로 크몽에 SNS 관리 서비스 등록 |
| 가격 전략 | 첫 클라이언트 50% 할인 프로모션 (19만→9.5만) |

| 후기 요청 | 첫 클라이언트에게 솔직 후기 요청 → 신뢰도 ↑ |

**효과**: 크몽 내 SNS 관리 카테고리 노출, 주 1~2건 문의

| 액션 | 상세 |
|------|------|
| 동네 상권 분석 | 주변 카페/식당/미용실 10곳 리스트업 |
